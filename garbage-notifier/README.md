# 垃圾車快到了提醒（新北市・Telegram）

垃圾車開到「你家的前一站」時，Telegram 跳通知提醒你準備出門。

- 資料：新北市環保局開放資料（政府資料開放授權條款，免費）
  - 新北市垃圾車路線：每個清運點的路線、清運序、表定時間、座標
  - 新北市垃圾清運車輛所在位置：垃圾車即時 GPS，約 2 分鐘更新一次
- 每分鐘檢查一次；一天只提醒一次。
- 如果前一站剛好沒抓到，車子到你家這站時也會補發一則通知。

## 資料（2026-11-09 已用真實資料測試）

- 即時位置：每分鐘抓一次「垃圾清運車輛所在位置」（全市約 200 台，一次就抓完）。
- 清運點：全市約 2.6 萬筆、18MB，Worker 免費方案解析不了，所以先把**淡水區 643 個清運點、16 條路線**
  打包進 `src/stops-data.js`。路線有異動時重新產生：

  ```sh
  node scripts/update-stops.mjs 淡水區
  wrangler deploy
  ```

- 淡水區相鄰兩站表定間隔中位數約 4 分鐘，所以「前一站」通常能提早 2～7 分鐘提醒；想更早可用 `/ahead 2`、`/ahead 3`。

## 設定步驟

跟 `../mushroom-notifier/README.md` 的步驟 1～7 一樣（建立 bot、KV、secrets、部署、設定 webhook、填 chat id），
只是名稱改成 `garbage-notifier`。之後：

1. 在 bot 聊天室點 📎 → 位置 → **傳送你家的位置**（傳一次就好，不用即時分享）。
2. bot 會列出附近的清運點，點你平常倒垃圾的那一站（例如 `/pick_251005_12`）。
3. 完成！之後垃圾車到前一站就會通知你。

## 指令

| 指令 | 說明 |
|---|---|
| `/status` | 查看設定 |
| `/ahead 3` | 改成提前 3 站提醒（預設 1 站＝前一站） |
| `/stop` / `/go` | 暫停／恢復（例如出國時） |

## 限制

- GPS 約 2 分鐘才更新一次，如果前一站離你家很近，可能直接跳過前一站，這時會在車子到你家這站時補通知。
- GPS 超過 10 分鐘沒更新的車會被忽略，避免用舊位置誤報。
- 車子訊號不好時位置會延遲（資料集說明有提到）。
